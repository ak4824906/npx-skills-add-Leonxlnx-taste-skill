# Brand project

Design skills for the brand project. Claude Code loads everything in `.claude/skills/` automatically in any session that opens this repo.

| Skill | Source | Use |
| --- | --- | --- |
| `brand-guidelines` | this project (v2) | Brand guideline books from a logo: reference matching, real type and photos, hard bans, self-critique. |
| `slop-audit` | this project | Pre-delivery check for AI tells on any design work. |
| `design-taste-frontend` | [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) @ 6010f91, MIT | Art direction and anti-slop rules for websites, with a direction library and a screenshot inspector. |
| `web-design-guidelines` | [vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills) @ 063bee9, MIT | Reviews UI code against Vercel's Web Interface Guidelines. |

The impeccable skill is installed on the account, so it is not copied here.

To use: give Claude your logo and brand info and say "make brand guidelines", or ask it to design or review a page.
